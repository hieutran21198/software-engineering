# Templates

Adapt these documents into your project's knowledge workspace. Replace prompts with decisions, evidence and explicit unknowns. Omit irrelevant medium sections. Templates have no creator-approved canon and contain no production claims.

- [Creative brief](creative-brief.md): the immediate creative objective and existing inputs.
- [Core contract](core-contract.md): reusable constraints in an owning domain.
- [Content entry](content-entry.md): one particular identity, fact, sequence or treatment.
- [Work skeleton](work-skeleton.md): a particular premise and linked composition.

A brief identifies the need; approved reusable direction belongs in Creative Direction. A work skeleton is Narrative Content. Use actual file links when entries exist, not dangling links to imagined records. Missing inputs remain named questions.
