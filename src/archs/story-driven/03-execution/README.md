# Creative Execution Skills

Use the roles together or in one session. Each loads relevant shipped guidance and the bundled utility skills. Adoption instructions describe optional discovery registration; no role requires a particular model or external service.

- [Coordinator](skills/story-driven-coordinator/SKILL.md): scope and next slice.
- [Architect](skills/story-driven-architect/SKILL.md): Core and knowledge ownership.
- [Author](skills/story-driven-author/SKILL.md): Content and composition.

The coordinator preserves the creator's decisions. Self-checks are part of each role. Creative prose and dialogue follow project voice, not the technical writing utility's default style.
