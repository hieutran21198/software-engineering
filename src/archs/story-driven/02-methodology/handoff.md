# Production Handoff

A handoff provides an outline and authoritative knowledge references, not a copied world bible.

For each work, provide its medium/scope, governing Core, linked participants and facts, causal spine, composition outline, slice-review findings and unresolved questions. Identify which unknowns block which production decisions. Do not claim creator approval or completed production without available evidence.

## Novel production

Hand off chapter/scene sequence, viewpoint and voice rules, entry knowledge, revelations and intended changes. Manuscript drafting can explore expression freely inside those constraints. If prose uncovers a contradiction, return it through knowledge revision rather than silently changing shared canon.

## Game production

Hand off supported actions/state, quests/scenes, choices and consequences, discovery requirements, playable treatments and applicable encounters/levels. Engine code, scripts, assets and build tests belong to downstream production. Do not make a narrative scripting tool mandatory for this knowledge workflow.

## Continuing the project

Agree the next useful slice instead of requiring every domain to be complete. Keep shared canon linked across works. Record local outcomes and deliberate divergences explicitly; never promote a playthrough outcome into shared historical fact by accident.
