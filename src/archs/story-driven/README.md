# Story-Driven Knowledge Framework

Build coherent story knowledge and a useful skeleton for a novel, a game, or several works sharing a world.

**Core** holds stable rules that constrain many creations. **Content** holds particular entities, events, sequences and treatments created under those rules. A world rule is not a city; a narrative rule is not a quest; art direction is not a character concept; a game design rule is not a weapon; a level design rule is not a level.

Start with the audience experience and the next useful story slice. You do not need a complete world encyclopedia. The framework supplies knowledge and production briefs; your manuscript, game implementation and finished assets consume that knowledge.

The bundle is self-contained. Research citations explain design choices; you do not need them or network access to operate it. Creative decisions remain yours. Structural review can expose contradictions and weak causality, but cannot determine artistic quality.
