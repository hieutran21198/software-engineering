# artifact-plane 1.17.0 — Redesign the authoring workbench

Compatible minor version. The browser application is redesigned and the overview response gains two optional title fields; existing HTTP routes, MCP tools, packets and edit operations stay compatible.

Artifact Plane 1.17.0 replaces the 1.16.0 workbench pages with one light, document-first layout: a top bar with project tabs, branch menu, uncommitted count, Refresh and More; a sidebar with current work, artifacts and their documents by title, and history behind a switch; and work, artifact, document, change, unit, flow, source, discovery and recorded-execution pages that show their title once, give each action one control on the page of the thing it changes, edit lists in place and open graphs only on request. The overview names documents and changes by their first heading. The knowledge editing operations, writer, Git actions and interfaces are unchanged.

This record holds no knowledge directories and no tasks. The originating plan and its evidence are in the [retained change](../../changes/change-workbench-redesign/tasks/README.md).
