# Task retention and navigation simplification — artifact-plane

## Reason and scope

Keep delivery tasks and their evidence with the originating change. Future versions contain artifact knowledge and reference delivery evidence without copying tasks. Preserve all established snapshots. Artifact Plane consumes the lifecycle and removes its standalone Workflow tab while retaining unit workflow exploration and legacy task access.

Baseline knowledge comes from 1.7.0. The task-copy rule in that baseline is superseded by this change. Prior validation does not prove new behavior.
