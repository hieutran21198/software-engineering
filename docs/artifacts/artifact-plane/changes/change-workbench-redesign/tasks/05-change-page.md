## Definition of Done

- [ ] The header shows the eyebrow with artifact, change and unit (or Add to unit), the change title once, and Read reason and scope; the phase steps link completed phases and offer Record self-check for the current one.
- [ ] The plan table shows status, ID, task, After and Done; a row expands in place with DoD checkboxes, evidence, Record evidence, Edit task (with Remove) and Open task document; "+ Add task" and Record plan self-check work; Graph shows the task canvas inline.
- [ ] Changed knowledge lists the change's documents by title with badges and an inline Compare.
- [ ] Ready for a version shows the readiness items with fix links, Prepare version with preview and acknowledgment, and Record publication review for a merged version without a review.
- [ ] No Overview, Plan or Review tabs remain, and no label combines Delivered and proposed.
- [ ] Screenshots at 1440 and 390 pixels match the Change mockup.
