# Initial Artifact Plane application

Build the smallest working local application for exploring ADD repositories. Readers need to see artifact relationships and the knowledge that explains them without editing the inspected repository.

## Proposed scope

One application in `apps/artifact-plane`. No established artifact prerequisites exist in this repository. The reusable ADD bundle supplies format guidance, not a project dependency.
