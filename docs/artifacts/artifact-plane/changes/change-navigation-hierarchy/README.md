# Show hierarchy in the navigation tree

## Reason and scope

On 18 October 2026 the owner reported that the sidebar tree does not separate parents from children, or one artifact from the next. In the interview the owner chose indented children with a vertical guide line, extra space before each artifact group, and medium weight for artifact rows.

Included: the presentation of the sidebar tree and its browser tests. Excluded: sidebar contents and behavior, pages, interfaces and ADD contracts.

Artifact Plane owns this change. The established baseline is Artifact Plane 1.17.0 on main, and ADD 2.6.0 is its established supplier; no ADD contract changes. Knowledge is edited in place on branch plane-navigation-hierarchy. This change belongs to the navigation-hierarchy unit.
