# Artifact Plane

Artifact Plane provides read-only exploration of local ADD repositories.

## Scope

Discover artifact knowledge and visualize artifact and element dependencies. Implementation belongs in `apps/artifact-plane`.

## Ownership

This artifact owns the repository explorer and its input interpretation rules.

## Current established version

1.1.0

## Established dependencies

None.

## Proposed release

Version `1.1.0` is prepared on the change branch. It adds collapsible type groups, compact records, logical element order, and a resizable inspector. Version `1.0.0` remains established on `main` until this knowledge and implementation merge.
