# Add visual representations to the ADD project knowledge

## Reason and scope

On 18 October 2026 the user asked to improve the current artifacts with the representations that the ADD 2.7.0 guide selects. The change adds them and corrects the defects in the passages they draw from. It changes no ADD rule and no bundle page. It belongs to the visual-artifacts unit.
