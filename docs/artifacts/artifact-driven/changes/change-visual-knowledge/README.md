# Establish visual knowledge design principles

## Reason and scope

On 18 October 2026 the user asked for evidence-based visual knowledge design principles for ADD and Artifact Plane: research the cognitive science and information visualization literature, select representations by the structure of the information, give AI agents operational authoring and validation instructions, apply the principles within the five phases, record the Artifact Plane implications, and show worked examples built from this repository's artifacts. The change is documentation only; se-adopt and Artifact Plane code do not change.

The change edits the bundle foundation, the end-user guidelines and the four role skills in the canonical and packaged bundle, and amends the change-delivery flow. It belongs to the visual-knowledge unit.

Excluded: Artifact Plane code and artifact knowledge, the story-driven bundle, image files, a diagram registry or front matter schema, a mandatory rendering tool, the repository overview and a release tag.

## Baseline and ownership

The baseline is established ADD 2.6.0 on main at 126990d. Knowledge is edited in place on branch claude/visual-knowledge; the protected branch holds the established baseline. Artifact Plane is affected only as a reader of the guidance; its implementation directions are recorded in the specification, and no Plane change is opened. This is the artifact's single active change.
