# Runbook guide

## Scope and location

Coordinator, as implementer. Bundle files in `docs/artifact-driven`: a new page `06-guidelines/runbooks.md` with the opening table, the seven runbooks after-merge, renumber, amendment, stop, reverse, live-check and failed-check in the form of specifications/runbooks.md, and the material test; one row in the `06-guidelines/README.md` index.

## Definition of Done

- [ ] `06-guidelines/runbooks.md` opens with a table of the seven situations with links, and each runbook has When, Inputs, Steps, Done when and Owner decides in this order, with the content of its contract row.
- [ ] Each step that applies a rule of another page links to that page; a reading check of each runbook against the pages that it links finds no restated or contradicting rule.
- [ ] The page states the material test of the contract once, and commands appear only in text fences.
- [ ] The guideline index lists the page with its purpose.
