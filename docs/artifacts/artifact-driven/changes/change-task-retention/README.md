# Task retention and navigation simplification — artifact-driven

## Reason and scope

Keep delivery tasks and their evidence with the originating change. Future versions contain artifact knowledge and reference delivery evidence without copying tasks. Preserve all established snapshots. ADD owns the lifecycle and delivered guidance.

Baseline knowledge comes from 1.2.0. The task-copy rule in that baseline is superseded by this change. Prior validation does not prove new behavior.
