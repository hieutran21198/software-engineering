# artifact-driven 2.9.0 — evidence-linked claims

Minor version. Records may declare an optional `claims` list for consequential decisions, assumptions, hypotheses, root causes, unknowns and risks. Each claim carries a status that describes evidence, never approval, an evidence basis, sources and the cheapest check. The writing interface sets `verified_by`, and only consequential claims are recorded. The bundle guidance, the definitions, the plan review and the three role skills state these rules. Existing records stay valid without edits, so no consumer must change.

This record holds no knowledge directories and no tasks. The originating plan and its evidence are in the [retained change](../../changes/change-claim-records/tasks/README.md).
