# artifact-driven 2.7.0 — change impact semantics

Compatible minor version. A new contract, specifications/change-impact.md, defines what "affected" means for ADD knowledge: the tiers changed, direct, transitive, potential and unresolved; a propagation rule for every declared and derived relationship type; the explanation record; the coverage statement; and how the phases use the result. The impact-analysis definition names the tiers, and the end-user guideline Assess Change Impact explains how to read an answer and use it in each phase. No front matter field is added and existing knowledge validates unchanged.

This record holds no knowledge directories and no tasks. The originating plan and its evidence are in the [retained change](../../changes/change-impact-semantics/tasks/README.md).
