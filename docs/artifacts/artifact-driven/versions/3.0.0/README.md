# artifact-driven 3.0.0

Major: consumers follow changed rules. A small change commits its phases once and its request is the plan approval, the plan proposes a level that approval confirms, tasks drop the Prerequisites section, and the Go package that embeds the bundle moves to `docs/artifact-driven`. Change tiers, requirement IDs with `covers`, single-source records, a validator in the default install and 400-word role skill cores make the delivery cost scale with the change; existing records stay valid.

The plan and its evidence are in the [retained change](../../changes/change-delivery-improvements/tasks/README.md).
