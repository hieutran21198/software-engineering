# artifact-driven 3.1.0

Minor: the bundle gains guidance and two lifecycle rules; no record format, field or existing rule changes, and existing records stay valid. Seven runbooks give the coordinator ordered steps after a merge, when the protected branch moves, after an amendment, when a change stops, to reverse a version, for a live check and for a failed check. A change that stops leaves no record on the protected branch, and a reversal is a new change with a higher number.

The plan and its evidence are in the [retained change](../../changes/change-runbooks/tasks/README.md).
