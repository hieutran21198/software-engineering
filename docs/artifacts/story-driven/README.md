# Story-Driven Knowledge Framework

## Purpose and ownership

Repository maintainers own the reusable story knowledge architecture, creative workflow, templates, execution skills, adoption bundle, and documentation delivery. Consumer projects own their creative direction, canon, authored content, and production outputs.

## Dependency meaning

This is a knowledge-format dependency on ADD. It does not make creative authoring or a consumer runtime depend on ADD tooling.

## Knowledge

This artifact uses the in-place layout. Working knowledge is in requirements, specifications and decisions:

- [Requirements](requirements/framework.md) and [flow requirements](requirements/flows.md)
- [Specification](specifications/framework.md) and [flow contract](specifications/flows.md)
- [Decision](decisions/001-shared-knowledge.md)

Version records are in versions. Records 1.0.0 and 1.1.0 were converted from complete legacy snapshots; each one gives the Git command that finds its knowledge. Change records and retained delivery plans are in changes.
