# Methodology

The methodology defines how actors move one active change through Requirement, Specification, Plan, Implementation, and Version. Each phase consumes the completed output of the previous phase.

## Contents

1. [Workflow](workflow.md): Phase ownership, completion criteria, commits, and corrections.
2. [Dependencies](dependencies.md): Artifact execution order, element references, and preparation against proposed contracts.
3. [Validation](validation.md): Task checks, integration checks, evidence, and version establishment.
