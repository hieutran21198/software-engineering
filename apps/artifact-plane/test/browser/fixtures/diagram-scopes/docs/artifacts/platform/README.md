# Platform

Own the system views of the bookshop. The system views show the whole system: its boundary, its applications and data stores, and its deployment. Other artifacts own the parts that the views show. The owner table after each view names the owning artifact of each part.

The bookshop, its artifacts and its facts are invented for the tests of Artifact Plane.
